PROTECTED SECTION .

ENDCLASS .
CLASS zcl_kindergarten_garden IMPLEMENTATION .
METHOD plants .
DATA : studentID TYPE i , idx TYPE i .
idx = 1 .
DATA ( students ) = VALUE string_table ( ( |Alice| ) ( |Bob| ) ( |Charlie| ) ( |David| )
( |Eve| ) ( |Fred| ) ( |Ginny| ) ( |Harriet| )
( |Ileana| ) ( |Joseph| ) ( |Kincaid| ) ( |Larry| ) ).
DESCRIBE TABLE students LINES DATA ( length ).
LOOP AT students INTO DATA ( stud ).
IF stud = student .
studentID = sy-tabix .
ENDIF .
ENDLOOP .
SPLIT diagram AT '\n' INTO TABLE DATA ( dia ).
LOOP AT dia INTO DATA ( row ).
IF studentID > 1 .
idx = ( studentID - 1 ) * 2 .
ELSE .
idx = studentID - 1 .
ENDIF .
DATA ( plants ) = row + idx ( 2 ).
DATA ( len ) = 2 .
idx = 0 .
WHILE idx < 2 .
IF plants + idx ( 1 ) = 'C' .
APPEND |clover| TO results .
ELSEIF plants + idx ( 1 ) = 'G' .
APPEND |grass| TO results .
ELSEIF plants + idx ( 1 ) = 'R' .
APPEND |radishes| TO results .
ELSEIF plants + idx ( 1 ) = 'V' .
APPEND |violets| TO results .
ENDIF .
idx += 1 .
ENDWHILE .
ENDLOOP .
ENDMETHOD .
ENDCLASS .
