CLASS zcl_collatz_conjecture DEFINITION
PUBLIC
FINAL
CREATE PUBLIC .
PUBLIC SECTION .
METHODS ret_steps IMPORTING num TYPE i
RETURNING VALUE ( steps ) TYPE i
RAISING cx_parameter_invalid .
PROTECTED SECTION .
PRIVATE SECTION .
ENDCLASS .
CLASS zcl_collatz_conjecture IMPLEMENTATION .
METHOD ret_steps .
DATA ( input ) = num .
IF input < 1 .
RAISE EXCEPTION TYPE cx_parameter_invalid .
ENDIF .
WHILE input <> 1 .
steps = steps + 1 .
IF input MOD 2 EQ 0 .
input = input / 2 .
ELSE .
input = 3 * input + 1 .
ENDIF .
ENDWHILE .
ENDMETHOD .
ENDCLASS .
