CLASS zcl_prime_factors DEFINITION
PUBLIC
FINAL
CREATE PUBLIC .
PUBLIC SECTION .
TYPES integertab TYPE STANDARD TABLE OF i WITH EMPTY KEY .
METHODS factors
IMPORTING
input TYPE int8
RETURNING
VALUE ( result ) TYPE integertab .
PROTECTED SECTION .
PRIVATE SECTION .
ENDCLASS .
CLASS zcl_prime_factors IMPLEMENTATION .
METHOD factors .
data ( i ) = 2 .
data ( n ) = input .
while n > 1 .
while n mod i = 0 .
APPEND i to result .
n = n / i .
ENDWHILE ..
i = i + 1 .
ENDWHILE .
ENDMETHOD .
ENDCLASS .
