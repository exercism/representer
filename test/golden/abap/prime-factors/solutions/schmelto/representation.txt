CLASS zcl_prime_factors DEFINITION
PUBLIC
FINAL
CREATE PUBLIC .
PUBLIC SECTION .
TYPES integertab TYPE STANDARD TABLE OF i WITH EMPTY KEY .
METHODS factors
IMPORTING
input TYPE int8
RETURNING
VALUE ( result ) TYPE integertab .
PROTECTED SECTION .
PRIVATE SECTION .
ENDCLASS .
CLASS zcl_prime_factors IMPLEMENTATION .
METHOD factors .
DATA div TYPE i VALUE 1 .
WHILE input <> div .
div = div + 1 .
IF input MOD div = 0 .
input = input / div .
APPEND div TO result .
div = 1 .
ENDIF .
ENDWHILE .
ENDMETHOD .
ENDCLASS .
