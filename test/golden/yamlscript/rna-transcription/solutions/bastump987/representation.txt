# At the end of the day, it's not the biggest deal. I am, however,
# curious about what the idiomatic "\"YAMLScript" way" of having the
# `else` block throw and error/panic would be though. What if I were
# writing a program in which it was absolutely unacceptable to be
# parsing a nucleotide that did not map to one of the know values?
defn to-rna(dna):
  join:
    each nucleotide dna:split:
      condp eq nucleotide:
        'G': 'C'
        'C': 'G'
        'T': 'A'
        'A': 'U'
        else: ''
