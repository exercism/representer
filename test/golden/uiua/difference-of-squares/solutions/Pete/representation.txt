# Calculate the square of the sums of the first N natural numbers
# using the formula (n(n+1)/2)²
# SquareOfSum ? Number
SquareOfSumFormula ↚ |1 ⁿ₂÷₂×⊃(∘|+₁)
# Calculate the sum of the squares of the first N natural numbers
# using the formula n(n+1)(2n+1)/6
# SumOfSquares ? Number
SumOfSquaresFormula ↚ |1 ÷₆××⊃(∘|+₁|+₁×₂)
# Calculate the square of the sums of the first N natural numbers,
# by brute force
# SquareOfSum ? Number
SquareOfSumIterative ↚ |1 ⁿ₂/+⇡+₁
# Calculate the sum of the squares of the first N natural numbers.
# by brute force
# SumOfSquares ? Number
SumOfSquaresIterative ↚ |1 /+ⁿ₂⇡+₁
# Calculate the square of the sums of the first N natural numbers
# SquareOfSum ? Number
SquareOfSum ← |1 SquareOfSumFormula
# Calculate the sum of the squares of the first N natural numbers
# SumOfSquares ? Number
SumOfSquares ← |1 SumOfSquaresFormula
# Calculate the difference between the square of sums and sum of squares
# DifferenceOfSquares ? Number
DifferenceOfSquares ← |1 -⊃(SumOfSquares|SquareOfSum)
