# Compute the next generation using Conway's Game of Life rules
# NextGeneration ? CurrentGeneration
# Helper function: Count live neighbors for each cell
# Counts neighbors by shifting matrix in all 8 directions and summing
CountNeighbors ← /+⬚0↻⊂A₂C₂
# Helper function: Apply Conway's Game of Life rules
# Rules: Live cell survives with 2-3 neighbors, dead cell becomes alive with exactly 3 neighbors
ApplyRules ← ⨬(=3|∊2_3)
# Main Tick function: Compute next generation
Tick ← ApplyRules⟜CountNeighbors
