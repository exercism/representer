# Remove any hyphens from string
# DehyphenatedString ? RawString
DeHyphenate ↚ ▽⊸≠@-
# Looks like an ISBN (without hyphens)
# Boolean ? DehyphenatedISBN
LooksOK ↚ ≠₀ ⊢△ regex "\"^\\\\d{9}[\\\\dX]$\""
# Array 10 down to 1
Multipliers ↚ ⇌+₁⇡10
# Is ISBN checksum OK
# Boolean ? DehyphenatedISBN
ChecksumOK ↚ =₀◿₁₁/+× Multipliers ≡(⨬(-@0|10◌)⊸=@X)
# Check if a given ISBN is valid
# ValidationResult ? ISBN
IsValid ← |1 ⨬(0◌|ChecksumOK) ⊸LooksOK DeHyphenate
