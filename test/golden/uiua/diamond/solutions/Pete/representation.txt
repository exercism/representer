# Make an array of the indices where the letter goes in each row of the diamond
# IndicesArray ? Letter
MkIndices ← ≡⊟ -: -₁⧻ .. ⊂ ⍜: ↘₁ ⇌. ⇡+₁ (-@A)
# Make an array of blank strings of the right length for our diamond
# BlankStringsArray ? Letter
MkBlanks ← ↯ ⧻.↯⊙@\s +₁×₂(-@A)
# Make an array the letters for each row of the diamond
# LettersArray ? Letter
MkSeq ← ⊂ ⊃(∘|↘₁⇌) ⍜(-@A)(⇡+₁)
# Make the 3 arrays of parameters to feed to the ≡ (rows) function
# IndicesArray BlankStringsArray LettersArray ? Letter
MkParams ← ⊃(MkIndices|MkBlanks|MkSeq)
# Make a row of the diamond
# DiamondRow ? Indices BlankString Letter
RowFunc ← ⍜⊏ ◌
# Output the diamond shape for a given letter
# Rows ? Letter
Diamond ← ≡RowFunc MkParams
