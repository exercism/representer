# Method names from Rust's standard library that exercise solutions often
# call or implement. If a student defines a method with one of these names,
# the Rust representer keeps the name, so a student's sum that calls
# Iterator::sum can't merge with a student's max that calls Iterator::max.
# It also keeps the methods that the language's operator and conversion
# traits require (add, eq, fmt, next and so on).
#
# This list was written by hand from the types and traits used most in
# exercises: Option, Result, Vec, String, str, char, HashMap, slices,
# iterators, the integer and float types, and std::ops, std::fmt and
