# Function names from Elixir's standard library that exercise solutions often
# call or implement. If a student defines a function with one of these names,
# the Elixir representer keeps the name, so a student's reverse that calls
# Enum.reverse can't merge with a student's sort that calls Enum.sort. It
# also keeps the callbacks that OTP behaviours and protocols require (init,
# handle_call, to_string and so on).
#
# This list was written by hand from the modules used most in exercises:
# Kernel, Enum, String, List, Map, MapSet, Keyword, Integer, Float, IO,
# Access, GenServer, Agent, Task, Date, Time, DateTime, Range, Stream and the
# String.Chars, Inspect, Enumerable and Collectable protocols.
